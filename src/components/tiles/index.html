Tiles

Components reference.

Combine shared colors and finishes with icon, degree, date, funding, or navigation content.

Tiles

Color, layout, and finish are separate. Pair .tile with a color and a content layout such as .icon-tile, .date-tile, or .program-tile. A bare tile does not set a square size by itself.
