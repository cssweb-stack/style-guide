College Website Style Guide

A shared foundation for department websites.

A practical reference for consistent, accessible department websites.

This guide documents the shared design system used by College of Social Sciences websites. It provides a common reference for colors, typography, layouts, and reusable components while allowing each department to maintain its own identity and content.

Use the navigation to choose a topic. Each page shows a focused set of examples, their names, and guidance for using them. Code remains available in expandable panels when you need it.

The guide reflects the current shared styles. Design changes should be reviewed before they are released to connected department websites.
