Lists

Typography reference.

Use bullets for related items and numbering for ordered steps. The examples include all four nested combinations.

Lists

Nested lists belong inside the parent list item. All four combinations below use the shared list rules.

Unordered list

ul

  • First item
  • Second item
  • Third item
