Working safely

  1. Edit local source in VS Code and preview the complete site.
  2. To test shared changes without releasing them, create a preview branch of css-shared. Keep production sites configured to main.
  3. Point the guide build at the preview branch using shared.config.json. Its local preview uses the checked-out local shared folder; its online build uses the configured ref.
  4. After review, merge approved shared changes to main. Connected sites receive them when they rebuild.

A local shared checkout on a preview branch affects every local preview using that folder. Published sites remain on their configured GitHub branch. Use a separate local shared checkout for simultaneous stable and preview work.
