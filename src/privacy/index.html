Privacy Information

About this reference site.

This guide has no analytics configured and no information submission forms.

Search sends a submitted query to Google. Bootstrap loads from jsDelivr, and the Inter font loads from Google Fonts. Your browser connects to those providers to request their resources.

Copy buttons use your browser’s clipboard only when selected. The guide shows examples of the current shared styles; it does not edit or publish design settings.

Sample names and example.invalid email addresses are fictional. The Bluesky example does not request a live feed.

For website questions, email cssweb@hawaii.edu. See the UH Mānoa Privacy Statement.
