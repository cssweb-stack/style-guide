Dividers and Spacing

Layout reference.

Choose a small, medium, or large separator. Divider size controls surrounding space; spacers reserve space without a line.

Dividers and spacing

Small: 0.75rem; medium: 1.5rem; large: 2.25rem on each side. Spacers reserve the same total height without drawing a line.
