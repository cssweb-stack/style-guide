Media Rows

Layout reference.

Pair a photo or colored tile with text using one of three centrally controlled left-column widths.

Media and text rows

Small: 7rem; medium: 10.125rem; large: 13.25rem. Gap: 1.5rem. Values are read from the shared tokens.

Small left column

.media-row .media-row-small

Widths come from --media-width-small. Rows stack below 768px; these are current values, not new sizing changes.
