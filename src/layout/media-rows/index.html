Media Rows

Layout reference.

Pair a photo or colored tile with text using the same shared two-column layout.

Media and text rows

Every ordinary photo and icon row uses .media-row: a 189px left column, a flexible right column, a 1.5rem column gap, and a 2.25rem bottom margin. Rows stack below 768px. Photo frames and icon styling are independent of layout.

Event dates, contact/map rows, and chair/profile messages retain their dedicated dimensions using the same structure. Homepage degree boxes, faculty profiles, and advisor cards keep their separate component layouts.

Photo and text

.media-row

The photo uses the same column, gap, and bottom spacing as an icon box.
