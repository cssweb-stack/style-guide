Heroes reference.

The full-width image on this page demonstrates this hero combination.

What this example shows

The hero above displays a location label. The separate attribution bar is turned off.

Hero sizing, responsive behavior, animation, and graphic treatment are shared. The image, location, crop, and credit are local content.

Hero display settings

site.hero.enabled · decorative · showLocation · showAttribution

The label and attribution switches are independent. A credited image without a location label is also supported.

Code and usage
{% raw %}/* In src/_data/site.json, or as a page-level site.hero override */
{
"hero": {
"enabled": true,
"decorative": false,
"showLocation": true,
"showAttribution": false
}
}{% endraw %}
