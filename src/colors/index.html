Colors

Institutional colors, grays, and accents.

Keep the shared foundation distinct from the accent palette. Choose a color by its role, then use the matching component variant.

Institutional Colors Grays Accent Colors Complete CSS Inventory

Institutional Colors

Brand and functional colors used in the shared site foundation. UH Green retains its university-specific name.

UH Green

#024731

--uh-green

University bar, department footer, and shared navigation states.

Link Blue

#0a58ca

--link-color

Standard text links. This functional color is separate from the decorative accent palette.

Grays

Neutral colors include white and black as well as the grays used for backgrounds, text, borders, and dividers. The unit bar and navigation currently share the same Light Gray.

White

#ffffff

--light

Page backgrounds, text on dark backgrounds, and white divider bars.

Black

#222222

--text

Used for body text. This softened black is also the current --color-black tile value.

Light Gray

#f7f7f7

--light-gray

Both the unit-name bar and the navigation background use this same gray.

Dark Gray

#2d2d2d

--dark-gray

Subfooter background.

Border Gray

#d2d2d2

--border-gray

Unit-bar border, hero separator line, and several card and media borders.

Divider Gray

#e2e2e2

--nav-divider

Section dividers, dropdown separators, and the shared frame border.

Icon Gray

#888888

--icon-gray

Shared contact and content icon treatments.

Note Gray

#555555

--note-color

Small explanatory notes.

Complete CSS Inventory

This audit covers the shared common.css and shell.css, the GEO, SOC, and WGSS local stylesheets, and the guide’s own stylesheet. The three department override files currently contain no color declarations.

Additional values include keyboard-focus blue, hero-credit link blue, mini-callout gold, menu-icon grays, Bluesky card backgrounds, and transparent overlays and shadows. They are documented below without silently changing the shared design.

The inventory lists written CSS values. Short hex, long hex, and named forms can represent the same color, such as #fff, #ffffff, and white. currentColor and transparent describe behavior rather than additional fixed colors. Checkerboards show transparency.
